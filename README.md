# Alpha Nation Website

A Next.js 16.4.6 website with a separate Supabase backend, secure staff admin, server-verified public forms, TOTP MFA and Cloudflare Workers deployment configuration.

Start with:

- `README-ALPHA-NATION.md` — project overview and local setup
- `SECURITY-AND-LAUNCH-AUDIT.md` — verified controls and remaining launch blockers
- `CLOUDFLARE-DEPLOYMENT.md` — environment setup, secrets and deployment
- `SUPABASE-ADMIN-SETUP.md` — owner account and staff provisioning

The existing Alpha Nation CRM is a separate project and is not part of this repository/package.
